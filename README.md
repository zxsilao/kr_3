# NovaPlay

Учебный HTML/CSS-проект интернет-магазина компьютерных игр. Выполнено на основе КР1 с учетом требований КР3.

## Структура

- `index.html` — главная страница с героем, подборкой популярных игр и модальным окном заявки;
- `catalog.html` — каталог товаров с карточками продуктов;
- `product.html` — страница отдельного товара с галереей, характеристиками и описанием;
- `order.html` — страница оформления заказа с формой и итоговой суммой;
- `contacts.html` — контакты проекта;
- `css/style.css` — общие стили (переменные, Typography, сетка, компоненты);
- `css/responsive.css` — адаптивные стили (медиазапросы, моб. меню, печать);
- `js/main.js` — липкий заголовок, моб. меню, galerie товара, формы заказа;
- `images/` — изображения проекта.

## Требования КР3 (выполнено)

- [x] Семантическая HTML5-разметка (`main`, `section`, `article`, `nav`, `figure`, `fieldset`, `legend`);
- [x] CSS-переменные для цветов, шрифтов, отступов, радиуса;
- [x] Адаптивный дизайн: медиазапросы для мобильных, планшетов и десктопов;
- [x] Мета-тег `viewport` для корректного отображения на мобильных устройствах;
- [x] Липкий (sticky) заголовок при прокрутке;
- [x] Мобильное меню (гамбургер) с `aria-expanded`;
- [x] Страница товара с галереей изображений, характеристиками, ценой и кнопками покупки;
- [x] Страница оформления заказа с валидацией формы (имя, email, телефон, адрес, дата, способ оплаты, согласие);
- [x] Модальное окно заявки (`<dialog>`) на всех страницах;
- [x] accessibility: skip-link, `aria-label`, фокус-видение, снижение движения (`prefers-reduced-motion`);
- [x] print-стили для заказа;
- [x] HTML5-валидация форм (required, pattern, minlength, maxlength, type="email|tel|date");

## Технологии

HTML5, CSS3, минимальный JavaScript (без зависимостей).

## Как открыть

Откройте любой HTML-файл в браузере. Сервер не требуется — это статический фронтенд.
